CSS Variables

Store and reuse values throughout your stylesheet

Defining CSS Variables?

Variables are defined with two dashes and are usually placedin :root so they are avaliable globally.

:root {
                --primary-color: #667eea;
                --font-size: 1rem;
                --spacing: 1.5rem;
        }

:root — targets the highest-level HTML element and makes the variables available throughout the entire document.

--name — all custom properties start with two dashes --

Using Variables

Use the var() function to apply a variable's value to a CSS property

body {
                    background: var(--primary-color);
                    font-size: var(--font-size);
                    padding: var(--spacing);
        }

var() — retrieves the value of a custom property

Fallback: var(--color, blue) uses blue if --coloris not defined

Scope

Variables can be global or scoped to a specific element and its children.

/* Global variable */
        :root {
    --color: blue;
    }

    .card {
        --color: green; /* Scoped variable */
        background: var(--color);
    }

Global — defined in :root and available throughout the document

Scoped — defined within a specific selector and only available to that selector and its children

.card — will be green, everything else will be blue

Dynamic Updates

Variables can be updated dynamically using JavaScript, updating all elements that use them instantly.

document.documentElement.style.setProperty('--primary-color', 'red');

document.documentElement — refers to the root element of the document

style.setProperty() — updates the value of a CSS variable

Result:Everyelement using --primary-color updates instantly

Why use variables?

CSS Variables make stylesheets easier to maintain, theme , and update.

:root {
    --primary-color: #667eea; 
    }
/* change the primary color in one place and it updates everywhere */

Consistency: — one source of truth for colors and values

Theming — dark mode and light mode switching

Maintainability — change a variable, update the whole site
