Values and Sizing

What are CSS Values and Sizing?

CSS values define what a property is set to, and sizing controls the dimensions of elements. Understanding units and sizing methods is essential for creating responsive, consistent layouts.

Key principle: Choose the right unit for the job — some units are absolute, others are relative to context.

Absolute Units

Fixed units that don't change based on context.

.element {
                    width: 200px;
                    margin: 1cm;
            }

px — pixels, the most common absolute unit for screen display.

cm, mm, in — physical units, mainly used for print media.

When to use: Borders, shadows, fixed elements, and when you need precise control over layout.

Relative Units

Units that scale relative to something else — parent, root or viewport.

.element {
                padding: 2em;
                width: 50%;
        }

% — percentage, relative to the parent element's dimensions.

em — relative to the font size of the element itself.

rem — relative to the font size of the root element (usually <html>).

Best practice: Use rem for font sizes, % for layouts, and em for spacing within components.

Viewport Units

Units that scale relative to the size of the browser window or viewport.

.element {
                height: 100vh;
                font-size: 5vmin;
        }

vw — viewport width (100vw = full width)

vh — viewport height (100vh = full height)

vmin — smaller dimension vw or vh

vmax — larger of vw or vh

Best practice: Fullscreen layouts, hero sections, and when you want elements to scale with the browser window.

Width and Height

Set the dimensions of an element

.element {
                width: 300px;
                height: 200px;
        }

Default: Block elements are 100% wide, height is auto.

auto: Browser calculates the size

fit-content: Size based on the element's content

Min and Max

Set boundaries for an element's dimensions

.element {
                min-width: 200px;
                max-width: 800px;
                min-height: 100px;
        }

min-width / min-height: Prevents the element from shrinking below a certain size.

max-width / max-height: Prevents the element from growing beyond a certain size.

Common use: Use min/max to create flexible layouts that adapt to different screen sizes.

calc() and clamp()

Functions that let CSS do math and set responsive boundaries.

.element {
                width: calc(100% - 20px);
                font-size: clamp(1rem, 2vw, 2rem);
        }

calc() — allows mathematical expressions to determine size.

clamp() — sets a value that is constrained between a defined minimum and maximum.

Example: clamp(1rem, 2vw, 2rem) means the font size will be at least 1rem, scale with 2vw, but not exceed 2rem.
